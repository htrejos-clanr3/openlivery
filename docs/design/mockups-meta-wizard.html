Paso 6 · Permisos

La validación falló. El paso no avanza hasta corregirlo.

Error de Meta
Falta un permiso de Meta. El usuario del sistema no tiene whatsapp_business_management; añádelo y genera un token nuevo.
Ver detalle técnico

(#200) Requires whatsapp_business_management permission

Cómo solucionarlo

  1. Entra a business.facebook.com → Configuración del negocio → Usuarios → Usuarios del sistema.
  2. Selecciona el usuario que generó el token y añade whatsapp_business_management y business_management.
  3. Genera un token nuevo y pégalo abajo: el anterior no hereda permisos.
