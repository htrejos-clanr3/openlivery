# Installation

Two paths, same result:

- `INSTALL-PROMPT.md` - paste the block into an AI assistant and follow it. Best
  for operators who are not developers.
- `README.md` at the repository root - the manual, command-by-command path.

Verification is the same in both: `./scripts/verify_production.sh` and, for the
business cycle, `python3 scripts/e2e_full.py`.
